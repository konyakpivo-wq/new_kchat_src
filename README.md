# New KChat

New KChat is an Android Telegram client.

## Version 0.1.0

This first build contains the application shell and GitHub Actions APK builder.

Telegram connection is not enabled yet.

## Telegram API

For a real Telegram client, New KChat will use Telegram API/TDLib. A separate Telegram api_id and api_hash are required for the application.

Do not commit private credentials to this repository.

## Build

GitHub Actions builds a debug APK automatically after pushes to main.
